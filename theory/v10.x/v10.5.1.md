# v10.5.1 双模产业链分析框架（最新稳定版）

## 概述

v10.x 是 **产业链 + 价值网双模分析** 框架，适用于 **互联网、AI、平台型、生态型** 行业。

### 与 v9.2 的核心差异

| 维度 | v9.2 | v10.x |
|------|------|-------|
| 链结构 | 线性（链） | 链 + 价值网（双模） |
| 枢纽角色 | 环节参与者 | 建网者 / 生态构建者 |
| 价值来源 | 利润集中 | 价值共创 + 网络效应 |
| 推荐场景 | 制造、消费 | 平台、AI、生态 |

---

## 双模结构

```
                   传统产业链（链模式）
                 ┌─────────────────────┐
        上游 ────► 中游 ────► 下游 ────► 服务
                 └─────────────────────┘
                            │
                 网络映射    │
                            ▼
                 ┌─────────────────────┐
                 │  价值网（网络模式）    │
                 │  - 建网者 (Builder)   │
                 │  - 参与者 (Participant)│
                 │  - 连接 / 流量 / 生态  │
                 └─────────────────────┘
```

---

## 价值网分析

### 角色分类
| 角色 | 说明 | 示例 |
|------|------|------|
| **建网者** | 构建平台/生态的核心企业 | 微信、淘宝、美团 |
| **参与者** | 在网络中提供/消费价值 | 商家、开发者、用户 |
| **连接者** | 跨网络桥接 | API 网关、支付接口 |

### 网络效应评估
1. **同边网络效应** — 更多用户吸引更多用户
2. **跨边网络效应** — 一边增长吸引另一边
3. **数据网络效应** — 数据积累提升服务质量
