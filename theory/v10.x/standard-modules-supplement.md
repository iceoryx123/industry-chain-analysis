## 模块F：增长引擎与天花板

### F1 增长驱动力分解

每个行业的增长可以拆解为以下驱动力，需要明确 **当前阶段的主要驱动力**：

| 驱动力 | 测量指标 | 生命周期阶段 | 典型当前增速 |
|--------|---------|:----------:|:----------:|
| **渗透率提升** | 普及率/覆盖率变化 | 导入→成长期 | 20-50%+ |
| **消费升级** | 均价/高端占比变化 | 成熟期 | 5-15% |
| **国产替代** | 国产化率变化 | 成长期 | 10-30% |
| **份额扩张** | 龙头市占率变化 | 成熟中后期 | 2-5%/年（龙头） |
| **品类扩展** | 新品类收入占比 | 成熟期 | 10-20%（新品类） |
| **量增（总量）** | 行业总产量增速 | 成→成熟 | 5-15% |
| **价增（通胀）** | 行业均价变化 | 成熟→衰退 | 0-5% |
| **周期波动** | 库存/产能周期 | 所有阶段 | -20% ~ +50% |

### F2 渗透率定位

**S型渗透率曲线** 是判断行业空间的核心工具：

```
渗透率
  ↑
100% ┤             ┌──── 饱和期（替换需求主导）
     │            ╱
 50% ┤       ┌─────── 成熟期（增量+存量）
     │      ╱
 10% ┤ ┌────── 成长期（快速渗透）
     │╱
  0% ┤── 导入期（试错阶段）
     └────────────────────────→ 时间
```

| 渗透率区间 | 阶段 | 投资策略 | 典型行业 |
|:---------:|:----:|---------|---------|
| 0-5% | 导入期 | 高风险高回报，选龙头 | AI大模型应用、eVTOL |
| 5-30% | 成长期 | 最佳投资窗口，高增速 | 新能源车(2020)、云计算 |
| 30-60% | 成→成熟 | 增速放缓，选性价比 | 智能手机(2015)、电商 |
| 60-90% | 成熟期 | 存量博弈，选龙头 | 白酒、家电、乳制品 |
| 90%+ | 饱和期 | 衰退替代风险 | 传统媒体、功能手机 |

### F3 天花板判断

**增长空间 = (渗透率上限 - 当前渗透率) × 潜在受众**

需要回答三个问题：
1. **渗透率上限是多少？**（100%？还是技术限制？）
2. **到达天花板需要多久？**（5年？10年？20年？）
3. **天花板之后的增长来自哪里？**（品类扩展？出海？提价？）

### F4 增长质量评估

| 增长类型 | 质量 | 可持续性 | 案例 |
|:--------:|:----:|:--------:|------|
| **量增（渗透率）** | 🟢 高 | ★★★★ | 新能源车渗透率提升 |
| **价增（品牌力）** | 🟢 高 | ★★★★★ | 茅台提价 |
| **价增（成本推动）** | 🟡 中 | ★★ | 调味品成本转嫁 |
| **份额扩张** | 🟢 高（对龙头） | ★★★ | 海天从15%→30% |
| **并购扩张** | 🟡 中 | ★★ | 华润啤酒并购整合 |
| **价格战（以价换量）** | 🔴 低 | ★ | 快递单票收入持续下降 |
| **政策补贴推动** | 🟡 中 | ★ | 新能源补贴退坡后 |

## 模块G：周期定位

### G1 行业周期分类

| 类型 | 特征 | ROE波动 | 估值方法 | 代表 |
|:----:|------|:-------:|:--------:|------|
| **强周期** | 供需周期驱动，利润大起大落 | ±30% | PB-低位，PE-高位反向 | 航运、钢铁、石化 |
| **弱周期** | 受宏观经济影响，但不会极端波动 | ±10% | PE均值回归 | 汽车、建材、化工 |
| **成长周期** | 成长为主，周期为辅 | 0-20% | PEG | 电子、新能源 |
| **弱防御** | 需求稳定，受经济影响小 | ±5% | 股息率+PE | 医药、食品饮料 |
| **强防御** | 刚需+管制，几乎不受经济影响 | ±3% | 股息率 | 公用事业、电信 |
| **逆周期** | 经济越差表现越好 | 不相关 | 事件驱动 | 不良资产、折扣零售 |

### G2 周期位置判断框架

```
                    ┌── 顶部信号
                    │ • 产能利用率 > 90%
                    │ • 库存高企
                    │ • 新进入者增多
                    │ • ROE处于历史90%+分位
                    ↓
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │  底部    │ →  │  复苏    │ →  │  繁荣    │ →  │  回落    │
  │(买入窗口)│    │(持有)    │    │(减仓)    │    │(回避)    │
  └──────────┘    └──────────┘    └──────────┘    └──────────┘
      ↑                                           │
      │   底部信号                                │
      │ • 产能出清                                │
      │ • 行业亏损面扩大                          │
      │ • 资本开支降至冰点                        │
      │ • PB处于历史底部                          │
      └───────────────────────────────────────────┘
```

## 模块H：行业分化方向

### H1 为什么要看方向？

CR4=0.3 这个数值本身没有意义，**方向**才是关键：

```
CR4 0.3 但上升中  ← 龙头正在整合，利好龙头
CR4 0.3 但下降中  ← 竞争加剧，龙头失守
CR4 0.7 且稳定    ← 寡头格局，高利润但可能受监管
CR4 0.1 且上升    ← 从分散走向集中，最好的投资窗口
```

### H2 行业分化三种模式

| 模式 | 特征 | 财务信号 | 投资策略 |
|:----:|------|---------|---------|
| **赢者通吃** | 老大越强，老二老三艰难，尾部出清 | 龙头毛利率>行业平均>5%，尾部亏损 | 只买龙头 |
| **百花齐放** | 大家都有饭吃，差异化竞争 | 毛利率标准差小，都在盈利 | 选性价比 |
| **内卷衰退** | 大家一起降价，盈利恶化 | 毛利率和ROE同时下降，全行业亏损 | 回避或等出清 |

### H3 分化测量指标

| 指标 | 含义 | 数据来源 | 判断标准 |
|------|------|:-------:|---------|
| **前3/后3毛利率差** | 领先者 vs 落后者差距 | 多ticker计算 | >20pp=分化加剧 |
| **毛利率标准差趋势** | 行业内部分散程度 | 多ticker计算 | 上升=分化 |
| **龙头市占率变化** | 集中度方向 | 行业数据 | 上升=整合 |
| **尾部企业ROE** | 尾部生存状态 | 多ticker计算 | 持续为负=出清中 |

## 模块I：技术颠覆敏感性

### I1 颠覆风险指数

| 风险等级 | 含义 | 代表行业 | 投资影响 |
|:--------:|------|---------|:--------:|
| 🟢 **低风险** | 技术路线稳定，颠覆概率极低 | 食品饮料、白酒、调味品 | 护城河可持续 |
| 🟡 **中等风险** | 存在技术替代可能，但缓慢 | 汽车、银行、房地产 | 需要跟踪转型 |
| 🟠 **高风险** | 正在被新技术重构 | 传媒（AI）、零售（电商） | 估值需打折 |
| 🔴 **极高风险** | 商业模式可能被颠覆 | 传统IT（云化）、纸媒 | 避开除非有转型证据 |

### I2 颠覆来源检查清单

| 颠覆来源 | 问题 | 高危行业 |
|---------|------|---------|
| **AI替代** | 核心价值会被AI重构吗？ | 翻译、编程、客服、内容创作 |
| **平台化/去中间化** | 中间环节会被跳过吗？ | 商贸零售、经纪、传统媒体 |
| **电气化/减排** | 碳约束改变成本结构？ | 化石能源、高耗能制造 |
| **去中心化** | 中心化信任会被替代吗？ | 银行、交易所 |
| **生物技术** | 传统化学/材料被生物替代？ | 化工、农业 |
| **新能源替代** | 能源结构变化冲击？ | 煤炭、石油 |

### I3 行业防御能力评估

同样面对颠覆，有些行业能抵抗，有些不能：

| 防御能力 | 特征 | 代表 |
|:--------:|------|------|
| **文化/习惯锁定** | 消费者不愿改变 | 白酒("喝茅台谈生意") |
| **物理不可替代** | 地理/资源无法复制 | 京沪高铁、上海机场 |
| **监管保护** | 牌照/许可限制 | 银行、公用事业 |
| **网络效应锁定** | 生态迁移成本高 | Windows、微信 |
| **无法防御** | 纯价格竞争 | 出租车(被网约车颠覆) |

## 模块J：跨行业比较 — 相对吸引力矩阵

### J1 三维评分矩阵

将每个行业在三个维度上打分（1-10），形成相对吸引力判断：

```
              ← 增长(模块F) →
             低(1-3)   中(4-6)   高(7-10)
  ┌────────┬─────────┬─────────┬─────────┐
↑ │  高    │ 收租资产 │ 优质成长 │ 明星赛道 │
│ │ (7-10) │ 铁路/机场│ 白酒/医药│ AI算力   │
│ │        │         │         │         │
│ 质量    │ 周期性机会│ 稳健配置 │ 高弹性   │
│ (模块B)│ 中(4-6) │ 航运底部 │ 家电/乳业│ 新能源车 │
│        │         │         │         │
│ │  低    │ 价值陷阱 │ 看拐点   │ 泡沫区   │
│ │ (1-3) │ 建筑装饰 │ 钢铁/石化│ (谨慎)   │
↓ └────────┴─────────┴─────────┴─────────┘
```

### J2 五力汇总表

| 行业 | 增长分 | 质量分 | 周期分 | 颠覆风险 | 综合 | 当前建议 |
|:----:|:-----:|:-----:|:------:|:--------:|:----:|:--------:|
| | (模块F) | (模块B) | (模块G) | (模块I) | | |

> **注意**：综合分不是简单平均，不同投资者偏好不同——防御型投资者更看重质量分，成长型投资者更看重增长分。

### J3 相对估值锚定

跨行业比较的最终目的是回答"哪个更便宜"。需要结合：
- 该行业当前PE/PB在历史中的分位数
- 同类型行业之间的估值对比（如白酒 vs 啤酒的PE溢价）
- 增长调整后的PEG
