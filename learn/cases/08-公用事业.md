# 公用事业产业链结构性分析

## 第一部分：行业拆分

### 拆分审视

| 触发条件 | 判断 |
|----------|------|
| 生命周期阶段不一致 | **是**——火电（成熟/衰退——碳中和压力）vs 新能源发电（光伏/风电，成长期）vs 核电（重生/成长期——重启审批）vs 水务（成熟期）vs 燃气（成熟期——城市燃气普及率已高） |
| 客户群体完全不同 | 部分——电网面对全社会用户，发电企业面对电网（单一买方），水务/燃气面对居民和企业 |
| 技术路线和成本结构差异显著 | **是**——火电（燃料成本占70%+，重资产+可变成本高）vs 水电（无燃料成本，初始投资巨大但边际成本趋零）vs 光伏/风电（零燃料，低运维，间歇性）vs 电网（输配电资产，无燃料风险） |
| 定价逻辑不同 | **是**——火电/水电上网电价由政府核定（"标杆电价"→"市场化交易"），电网输配电价受"准许收益"管制（"成本加合理利润"），燃气价格部分联动上游（居民用气受管制），水务完全政府定价 |
| 可投资标的完全不重叠 | **是**——长江电力（水电）、华能国际（火电）、中国核电（核电）、三峡能源（新能源）、国电南瑞（电网设备）、华润燃气（燃气）、粤海投资（水务）是完全不同的投资标的 |

**拆分结论**：必须拆分。选取四个最具代表性的子行业进行四层分析：

1. **发电——火电**（传统主力电源，碳中和压力下的结构性衰退）
2. **发电——水电**（超级重资产+零燃料成本+资源稀缺性）
3. **发电——核电**（技术/政策双重壁垒+重生型增长）
4. **电网**（输配售——自然垄断+"通道型"争论的终极检验）
5. **水务与燃气**（简要对比）


## 第二部分：分析前强制前置

### 第零层·步骤一：国家权力形态识别

公用事业的国家权力形态高度统一——**价格管制权（核心）+ 准入管制权+ 规划引导权**。

| 国家权力形态 | 在公用事业的体现 | 对产业链的影响方向 |
|-------------|-----------------|:---:|
| **价格管制权（核心）** | 上网电价由政府核定/市场化交易（有价格上限）、输配电价"准许收益"管制、居民用气用水政府定价。企业的收入=政府允许的成本+政府允许的利润 | ↓↓↓ 严格限定利润空间——超额利润被管制清零 |
| **准入管制权** | 发电项目需"路条"审批（虽已简化但仍存）、核电牌照极稀缺、电网自然垄断（全国两张网）、城市燃气/水务特许经营权 | ↑ 强化在位者壁垒，限制新进入者 |
| **规划引导权** | 电力"十四五/十五五"规划（装机结构、电网投资）、碳中和路径图（煤电退出节奏、新能源装机目标）、水务"水十条" | → 定义行业方向——火电衰退、新能源增长 |
| **补贴/转移支付** | 可再生能源补贴（曾长期拖欠）、居民电价交叉补贴（工商业补贴居民）、农村电网改造中央投资 | ↑↓ 创造短期利润但不可持续（补贴退坡） |

**核心判断**：公用事业的枢纽质量完全取决于**准入管制（进入壁垒）与价格管制（利润上限）的博弈**——准入管制越强、价格管制越松（或定价机制越合理），枢纽质量越高。

| 子行业 | 准入管制强度 | 价格管制形态 | 对枢纽质量的净影响 |
|--------|:---:|------|:---:|
| 水电 | 极高（优质水电资源已基本开发完毕，大江大河站点不可复制） | 水电标杆电价（稳定）+市场化交易（有折价压力） | ↑↑ 进入壁垒极强，利润稳定 |
| 核电 | 极高（牌照审批国务院层面，进入壁垒全行业最高之一） | 核电标杆电价（稳定） | ↑↑ 进入壁垒极强 |
| 火电 | 中高（"路条"审批仍存在，但增量空间小） | 市场化交易（价格下行压力大）+燃料成本不可控 | →↓ 进入壁垒有限，利润受挤压 |
| 电网 | 绝对垄断（全国仅国网+南网两张骨干网） | "准许收益"管制（成本加合理利润，类似收益率管制） | → 物理垄断绝对，但利润受严格管制 |
| 水务 | 高（区域特许经营） | 完全政府定价（听证会制度） | → 区域垄断但提价困难 |
| 城市燃气 | 中高（特许经营+管道唯一性） | 居民用气政府定价，工商业部分联动 | → 接驳费一次性收入，售气利润薄 |

### 第零层·步骤二：框架适用性确认

四个子行业均不处于真衰退期或导入期早期，框架适用。


## 第三部分：子行业四层分析

### A. 发电——火电

#### 第一层A：时间定位——行业生命周期

| 维度 | 判断 |
|------|------|
| 阶段判定 | **成熟期向衰退期过渡**。在碳中和目标下（2030碳达峰、2060碳中和），煤电的角色正从"主力电源"向"基础保障+调峰"转变。新增煤电机组审批虽未完全停止（电力保供压力），但长期趋势是存量替代和利用率下降 |
| 需求增速 | 低个位数。全社会用电量随GDP增长，但煤电的发电小时数将趋势性下降（被新能源挤占）。煤电在总发电量中的占比已从2010年的80%降至当前的约55-60%，预计2030年降至40%以下 |
| 渗透率 | 已过峰值。煤电在中国的渗透率处于结构性下行通道 |
| CR3 | 高（五大发电集团——华能、华电、国电投、国家能源、大唐——占据煤电装机的大部分，但未形成定价权） |

**指标冲突裁决**：需求增速正（用电量增长）但煤电份额下降→渗透率下降→CR3高但无定价权。成熟期向衰退过渡。

**假衰退检验**：煤电当前的亏损（部分年份全行业亏损）是**真衰退的前兆，而非假衰退**——亏损的根源不是暂时的供需错配，而是结构性的成本挤压（煤价市场化但电价管制）+份额被新能源挤占+碳中和政策约束。这不是周期性问题，是结构性问题。

**输出**：成熟期向衰退过渡。非假衰退。框架适用。

#### 第二层：赛道基因

**周期/资源型**（火电利润高度取决于煤价和电价的"剪刀差"——煤价和电价均非火电企业可控）。

默认枢纽分布：资源拥有者层——但火电企业的"资源"是什么？是发电机组（重资产），而非稀缺的自然资源。火电的"资源"不具有稀缺性壁垒（新的火电机组可以被建设，且煤电在政策上不受欢迎）。

#### 第三层：枢纽识别

**去伪规则**：✅ 通过。

**枢纽判定**：

| 维度 | 分析 |
|------|------|
| 与上游（煤炭）关系 | **无议价能力**。煤炭是市场化定价，火电企业是价格的被动接受者。煤价上涨时火电亏损，煤价下跌时火电盈利——利润不由火电企业决定，由煤价决定 |
| 与下游（电网）关系 | **极弱议价能力**。电网是单一买方（单寡头买方），火电的上网电价由政府核定或通过市场化交易形成（有价格上限）。火电企业是"价格接受者" |
| 与竞争端关系 | 火电之间是同质化竞争（电力是同质产品），新能源在份额上结构性替代火电 |
| 利润稳定性 | **极不稳定**。历史上火电行业出现多次"全行业亏损→政策救助→再亏损"的周期循环。2021年煤价暴涨导致全行业巨亏，2022年后煤价回落+电价上浮后盈利修复——但这都是煤价驱动的，非火电自身能力决定的 |

**横向竞争校验**：

| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ❌（CR3虽高但对下游无议价权——电网是单一买方，价格被管制） |
| 无持续价格战？ | ⚠️（电力市场交易中火电之间竞争激烈，但价格战被"地板价"和"天花板价"框架约束） |
| 新进入者未快速增加？ | ✅（煤电新项目审批趋严，增量空间小） |

**一项通过，一项审慎，一项不通过。判定：价值附属。**

**物理必经与利润占优的双重校验**：

| 校验 | 判断 |
|------|:---:|
| 物理必经？ | ⚠️ 火电在电力系统中的角色是"压舱石"——当前仍不可完全替代（新能源间歇性需要火电调峰），但长期来看其"必经"属性随着储能技术和新能源占比提升而弱化 |
| 利润占优？ | ❌ 完全不具备。燃料成本被动接受+上网电价被动接受，上下游双向挤压 |
| 结论 | **连"物理必经"都在弱化，利润占优完全不存在——价值附属的判断坚实。** |

**超额利润来源**：无。火电企业是公用事业中"受上下游双杀"的典型。其周期性盈利完全取决于煤价的下行周期，而非自身的产业链位置优势。

**可投资性**：☑ 可投资，但**不推荐作为位置优势投资**。火电的投资逻辑是"煤价周期+政策救助预期+高股息（盈利时）"，这是周期博弈逻辑，而非枢纽质量逻辑。

**最终判断**：火电是价值附属。枢纽质量来自燃料成本周期的阶段性幸运，而非产业链位置优势。在碳中和趋势下，火电的"物理必经"属性将逐渐被储能和新能源替代所侵蚀——当前仍需火电调峰，但十年后不一定。

#### 第四层：价值评估（简评，因已判定为价值附属）

| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | B-C | 当前是电力系统的必需品（调峰+基础负荷），长期弱化 |
| 粘性 | C | 电网对特定火电企业无粘性——只要发得出电，谁的都行 |
| 边际成本 | C | 每多发一度电的燃料成本高昂（煤价占70%），边际成本不递减 |
| 经常性 | A | 持续发电，持续收入 |
| 资产效率 | C | 极重资产（火电机组投资巨大），资产周转率低 |

**综合：C级。** 与住宅开发同级，是框架迄今最低评级的行业之一。

**护城河类型**：无。

**极端生存能力**：B级（用电刚需支撑需求刚性，但燃料成本波动和高负债构成重大风险）。


### B. 发电——水电

#### 第一层A：生命周期

| 维度 | 判断 |
|------|------|
| 阶段判定 | **成熟期（优质资源已基本开发完毕）**。中国可开发水电资源约6.6亿千瓦，截至2024年已开发约4.3亿千瓦，剩余可开发的优质站点（大江大河、高落差）已极为稀缺。水电正从"增量开发"转向"存量运营" |
| 需求增速 | 零增长（发电量完全取决于来水量+已建成的装机容量，无法主动增长）。需求端用电量增长，但水电供给量受限于已建成的装机 |
| 渗透率 | 稳定——水电在中国电力结构中占比约15-17%，受来水量影响有丰枯波动 |
| CR3 | 极高（长江电力占据全国水电装机的约15%+，且拥有三峡、溪洛渡、向家坝等绝对稀缺资源） |

**输出**：成熟期。非假衰退。框架适用。

**关键特征**：水电是**供给侧完全锁定的成熟期**——优质资源已开发殆尽，增量空间极小，但存量资产具有"一旦建成、永续经营"的特质。大坝的设计寿命可达百年以上，折旧期满后仍可持续运营。

#### 第二层：赛道基因

**资源型**（水电站的核心价值来自河流落差和水量的自然资源——这是无法复制、无法替代的天然垄断资源）。

默认枢纽分布：**资源拥有者层**。

#### 第三层：枢纽识别

**去伪规则**：✅ 通过。

**枢纽判定**：

| 维度 | 分析 |
|------|------|
| 与上游（来水/资源）关系 | 水资源是天然的，无成本。"上游"是大自然——不存在议价问题。这是水电与其他所有发电方式的本质区别 |
| 与下游（电网）关系 | 强于火电——水电的上网电价稳定（标杆电价），且水电具有调峰能力（部分水电站），是电网偏好的清洁能源。但仍是单一买方，议价能力受限于电价管制 |
| 与竞争端关系 | **无直接竞争**——长江电力的三峡/溪洛渡/向家坝是独一无二的，不存在第二个竞争者。不同流域的水电之间不存在直接竞争（各发各的电，不争夺客户） |
| 利润稳定性 | **极高**。成本端——无燃料成本（最大的成本项不存在），只有折旧和人工。收入端——上网电价稳定（政府核定）。利润的唯一边际变量是来水量（丰枯波动），但长期平均来水量稳定 |

**横向竞争校验**：

| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ✅（具体水电站具有绝对的区域垄断性——三峡无可替代） |
| 无持续价格战？ | ✅（水电之间不存在竞争——不同的江，不同的水电站，不争夺客户） |
| 新进入者未快速增加？ | ✅（优质水电资源已基本开发完毕——最大的进入壁垒是"已无资源可供开发"） |

**三项全通过。判定：价值枢纽。**

**超额利润来源**：☑ 供给刚性（优质水电站址是不可复制的自然资源——这是最纯粹的"供给刚性"） ☑ 规模经济（超级水电站的投资巨大，但单位发电成本随规模递减——三峡的单位千瓦投资远低于小型水电站）

**定价权根基**：**暴力**——电网必须购买水电（清洁能源消纳是政策要求），且特定水电站的发电量无法被其他电源替代（三峡的发电量只有三峡能发）。

崩坏方式：暴力型——若出现极端干旱导致来水系统性减少（气候变化风险）；或电力市场化改革导致水电被迫与其他电源竞价（有价格下行风险，但水电的零燃料成本使其在竞价中具有绝对成本优势）。

**可投资性**：☑ 可投资（长江电力 600900.SH——全球最大水电上市公司，纯正度极高；华能水电 600025.SH——澜沧江流域）。

**元枢纽追问**：否——水电不为其他行业收税。但长江电力是电力行业内部的"元枢纽"（最大清洁能源供应商）。

**输出**：水电是价值枢纽。枢纽成因：自然资源垄断（不可复制）+零燃料成本+超长运营寿命。

#### 第四层：价值评估

**A. 五透镜**：

| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | **S** | 水电站一旦建成，其发电量是"必须上网"的（清洁能源优先消纳）。三峡的发电量无可替代。参照：支付清算网络（S级）——在电力系统中是必经的清洁电源 |
| 粘性 | **S** | 电网对特定水电站的粘性极高——一旦电力系统围绕三峡的发电能力进行规划布局，就不存在"更换供应商"的选项 |
| 边际成本 | **S** | 每多发一度电的额外成本趋近于零——无燃料成本，额外一度电只有微不足道的运维成本。参照：软件授权（S级）——接近零边际成本 |
| 经常性 | **S** | 发电是持续的（24/7/365），收入是永续的。参照：订阅制（S级） |
| 资产效率 | B | 初始投资极为巨大（三峡工程总投资约2000亿元），资产效率（ROA）受折旧影响，但折旧期满后ROA将跃升 |

**评级**：最低项资产效率（B）。四个S级。有S无C上调一档→**S级**（基准B上调至A，再上调至S）。

**这是框架继支付清算网络之后给出的第二个S级。** 水电在强制性、粘性、边际成本、经常性四个维度上均达到S级——只有资产效率（巨额的初始投资）是B级。这与支付清算网络（四个S级+资产效率A）的结构高度相似。

**护城河类型**：**根基型**——极致的自然资源垄断。三峡一旦建成，其护城河将存续百年以上——河流不会改道，大坝不会消失。这是全行业最持久的根基型护城河之一，与墓园和支付清算网络同级。

**B. 极端生存能力**：

| 维度 | 评级 |
|------|:---:|------|
| 需求刚性 | **S**（电力是现代社会绝对刚需，水电是清洁能源的压舱石） |
| 资产负债表 | B（水电企业有大量有息负债——建设期借款，但现金流极为充裕，债务逐年偿还。长江电力的资产负债率已从峰值80%降至40%以下） |
| 成本灵活 | **S**（无燃料成本——最大的成本项不存在。折旧是非现金支出。收入下降时利润等比例降，不存在火电的"煤价倒挂"风险） |

极端生存能力：**S级。** 与墓园、支付清算同级——在极端环境下，水电的物理资产和发电能力不受损，需求刚性不变，无燃料成本意味着不存在"成本倒挂"的致命风险。

**D. 质量变化趋势**：

| 维度 | 趋势 | 理由 |
|------|:---:|------|
| 枢纽势能 | →↑ | 碳中和趋势下清洁能源占比提升，水电的"压舱石"地位强化。抽水蓄能（利用水电大坝的储能能力）增加水电的电网调节价值 |
| 价值留存率 | ↑ | 折旧逐年减少（核心机组折旧期30-40年，折旧期满后利润将跃升）。长江电力折旧占收入比重约20-25%，折旧期满后这些将直接转化为利润 |
| 持久性 | ↑ | 大坝设计寿命百年以上。来水量的稳定性受气候变化影响，但大江大河断流的概率极低 |

**自我毁灭风险评估**：

| 类型 | 评估 |
|------|------|
| 傲慢型 | 低——水电是天然的自然垄断，没有"过度压榨客户"的能力（电价受管制） |
| 惯性型 | 低——水电不需要技术迭代，其价值来自自然资源而非技术领先 |
| 自噬型 | 低——水电企业的投资范围受限于水电资源，不存在盲目多元化到不相关领域的冲动 |

**水电是极少数"无自我毁灭风险"的行业**——你很难毁掉一座大坝的价值。

**证伪条件设计**：
- 极端气候变化导致核心流域来水量系统性减少（长江流域连续多年干旱）
- 电力市场化改革导致水电电价大幅下行（水电被迫与其他电源竞争，丧失价格稳定性）
- 大坝安全——极为罕见的超级地震或地质灾害摧毁核心大坝（概率极低但后果灾难性）
- 取消水电优先消纳政策（可能吗？在碳中和目标下几乎不可能）

**最终判断**：水电是公用事业中枢纽质量最高的子行业。五透镜S级+极端生存S级的"双S"组合，与支付清算网络同级——这是框架迄今给出的两个最高评价。**水电的独特优势在于：自然资源垄断（不可复制）+零燃料成本+百年寿命+折旧期后利润跃升+几乎无自我毁灭风险。长江电力是这一位置的纯正标的。核心风险是气候变化（来水量）和电价政策——这两个风险都是超长期和概率性的，而非结构性的。** 这是一个"不需要奔跑、不需要创新、甚至不需要管理的护城河——大坝自己会发电"。


### C. 发电——核电

#### 第一层A：生命周期

| 维度 | 判断 |
|------|------|
| 阶段判定 | **成长期（重启增长）**。中国核电在2011年福岛核事故后审批冻结，2019年后重启审批。2022-2024年连续每年核准8-10台新机组，"十五五"期间有望维持这一节奏。核电在中国电力结构中的占比仅约5%（vs 法国70%），提升空间巨大 |
| 需求增速 | 中高增速。装机容量将以每年8-10%的速度增长（新机组投产），发电量同步增长 |
| 渗透率 | 极低（5%），有大幅提升空间。碳中和目标下，核电作为稳定基荷电源（24/7/365运行，不受天气影响），在新型电力系统中的价值凸显 |
| CR3 | 极高。中国核电工业由中核集团和中广核集团双寡头主导（国电投有少量核电资产），CR3近乎100% |

**输出**：成长期（重生型——2011-2019年的审批冻结期是"政策性衰退"，重启审批后进入重生）。非假衰退。框架适用。

**关键特征**：核电是公用事业中**唯一具有显著成长性的子行业**（水电资源开发完毕，火电在衰退，新能源成长但间歇性）。核电的成长性来自渗透率极低+政策明确支持+审批加速。

#### 第二层：赛道基因

**科技/成长型**（核电技术壁垒极高——三代核电"华龙一号"是国家科技的名片） + **牌照型**（核电牌照是能源行业最稀缺的牌照之一——全国只有三张半：中核、中广核、国电投+华能（高温气冷堆示范工程））。

默认枢纽分布：**牌照持有者层** + **IP持有者层**。

#### 第三层：枢纽识别

**去伪规则**：✅ 通过。

**枢纽判定**：

| 维度 | 分析 |
|------|------|
| 与上游（核燃料/技术）关系 | 铀矿资源依赖进口（部分），但核燃料在核电成本中占比极低（约10%，远低于火电煤价的70%），燃料价格波动对利润影响极小。核电技术（华龙一号）已完全自主化，不存在技术卡脖子风险 |
| 与下游（电网）关系 | 核电是电网最偏好的电源类型之一——稳定基荷（24/7/365运行，不受天气影响），清洁（零碳），上网电价稳定（核电标杆电价0.43元/度左右，高于火电和水电）。电网对核电的消纳有政策保障 |
| 与竞争端关系 | **无竞争**。核电牌照极稀缺+核电选址极为有限（需要沿海+地质稳定+冷却水源充足），新进入者几乎不可能。双寡头之间不存在直接竞争（各建各的核电站，不争夺对方的站点） |
| 利润稳定性 | **极高**。核电的成本结构类似水电——初始投资巨大但燃料成本低（占比仅10%），运营期60年以上，折旧期满后利润跃升。核电的上网电价稳定，不受煤价波动影响 |

**横向竞争校验**：

| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ✅（双寡头近乎100%，且对电网有极强的议价地位——核电是电网不能缺少的稳定基荷） |
| 无持续价格战？ | ✅（不存在价格战——核电之间不存在竞争，核电与火电/水电/新能源之间是互补而非竞争关系） |
| 新进入者未快速增加？ | ✅（核电牌照和选址的壁垒极高，新进入者几乎没有可能性） |

**三项全通过。判定：价值枢纽。**

**超额利润来源**：☑ 牌照保护（核电牌照极稀缺） ☑ 供给刚性（核电选址的不可复制性——沿海+地质+冷却水+地震风险） ☑ 规模经济（核电机组单机容量越大，单位成本越低）

**定价权根基**：**暴力**（电网必须购买核电——稳定的基荷电源是电力系统的必需品，且清洁能源优先消纳）。

崩坏方式：暴力型——若出现重大核安全事故（类似福岛或切尔诺贝利），核电可能面临全面叫停和政治性衰退。这是核电行业唯一的、但也是最致命的尾部风险。

**可投资性**：☑ 可投资（中国核电 601985.SH——中核集团旗下核电运营平台；中国广核 003816.SZ/01816.HK——中广核旗下平台）。

**输出**：核电是价值枢纽。枢纽成因：牌照稀缺+技术壁垒+零碳稳定基荷+政策明确支持。

#### 第四层：价值评估

**五透镜**：

| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | **S** | 稳定基荷是电力系统的绝对必需品——新能源有间歇性，火电有碳排放，水电受来水影响。核电是唯一可以24/7/365不间断运行的清洁基荷电源 |
| 粘性 | **S** | 核电站一旦并网运行，电力系统规划将围绕其发电能力进行——电网对特定核电站的依赖是绝对的 |
| 边际成本 | A | 核燃料成本占比低（约10%），额外一度电的边际成本低。但核燃料成本不为零（需要定期更换核燃料），低于水电的S级但远优于火电的C级 |
| 经常性 | **S** | 核电站的年发电小时数高达7000-8000小时（vs 水电3000-4000，光伏1000-1500），是发电效率最高的电源。收入永续 |
| 资产效率 | B | 核电的初始投资巨大（单台华龙一号造价约200亿元），折旧周期长（综合折旧期30-40年），折旧期内资产效率受压制。但折旧期满后ROA将跃升（与水电同构） |

**评级**：最低项资产效率（B）。三个S级。有S无C上调一档→**A级**（基准B上调至A）。

**评级低于水电（S级）的原因**：核电的边际成本不如水电（核燃料有成本，虽然低但非零），核废料处理和退役成本构成远期负债。**但核电的成长性（↑↑）是水电（→）无法比拟的——一个是增长中的价值枢纽，一个是存量运营的价值枢纽。**

**护城河类型**：**根基型**（牌照+选址+技术+政策）。核电的护城河是三重锁定——行政（牌照）、物理（选址）、技术（三代核电的建造和运营能力）。

**极端生存能力**：

| 维度 | 评级 |
|------|:---:|------|
| 需求刚性 | **S**（电力绝对刚需） |
| 资产负债表 | B（核电企业有大量建设期负债，但现金流极充裕） |
| 成本灵活 | A（核燃料成本占比低，固定成本（折旧）是非现金支出） |

极端生存能力：**A-S级。** 核电的极端生存能力与水电相当——物理资产稳固，需求刚性S级。唯一的额外风险是核安全事故的尾部风险（概率极低，但一旦发生后果灾难性——这是极端环境下核电面临的特有"人为灾难"风险，而水电仅有"自然灾难"风险）。

**质量变化趋势**：

| 维度 | 趋势 | 理由 |
|------|:---:|------|
| 枢纽势能 | ↑↑ | 核电审批加速（"十五五"有望每年8-10台）+ 渗透率从5%向10%+提升+ 碳中和强化核电价值 |
| 价值留存率 | ↑ | 新机组投产推动规模效应（每增加一台机组，总部和运维成本摊薄）+ 折旧期满后利润跃升（长期） |
| 持久性 | ↑ | 核电运营寿命60年以上（可延寿至80年），在建和在运机组将持续贡献利润数十年 |

**自我毁灭风险评估**：

| 类型 | 评估 |
|------|------|
| 傲慢型 | **中高（核安全文化松懈）**——这是核电行业唯一的、但也是最重大的自我毁灭风险。福岛和切尔诺贝利都是傲慢（"我们的核电站绝对安全"）酿成的灾难。核安全文化是核电企业的生命线——一旦出现重大安全事故，整个行业可能被关停 |
| 惯性型 | 低——核电技术迭代慢，惯性不是主要风险 |
| 自噬型 | 低——核电企业的投资高度聚焦核电领域，不存在盲目多元化的冲动 |

**证伪条件设计**：
- 全球范围内发生重大核安全事故（影响程度类比福岛或切尔诺贝利），触发中国核电审批再次冻结
- 核电电价政策重大调整（如核电与新能源竞价，导致电价大幅下行）
- 核电新技术突破（如小型堆、聚变）改变了现有核电运营商的竞争格局
- 台海地缘冲突（部分核电站位于沿海，地缘风险是特有的"非自我毁灭"外部风险）

**最终判断**：核电是价值枢纽，五透镜A级+极端生存A-S级。枢纽质量略低于水电（S级）——因为核燃料有成本（边际成本A vs S）和核安全尾部风险（傲慢型风险中高）。**但核电的成长性（趋势三项全↑↑/↑）是水电（→/↑/↑）无法比拟的——这是公用事业中唯一同时具备"枢纽质量+成长性"的子行业。** 核心投资逻辑是"渗透率从5%向10%+跃升+审批加速+长期现金流折现"。唯一致命风险是核安全——这是再好的产业链位置也无法免疫的尾部风险。


### D. 电网

#### 第一层A：生命周期

| 维度 | 判断 |
|------|------|
| 阶段判定 | **成熟期**。电网是电力系统的"血管"，其生命周期与电力需求同步。增量空间来自新能源并网投资、配电网升级和数字化改造，而非用电量的增长 |
| 需求增速 | 低个位数。电网收入随用电量增长（售电量增速约3-5%），但输配电价受政府"准许收益"管制，利润率被锁定 |
| 渗透率 | 极高。中国电网覆盖率已接近100%（村村通电已实现） |
| CR3 | **绝对垄断**。国家电网+南方电网（两张网），CR2=100% |

**输出**：成熟期。非假衰退。框架适用。

#### 第二层：赛道基因

**基础设施型**（电网是国民经济的底层基础设施——具有绝对的自然垄断属性）。

默认枢纽分布：**牌照垄断层**。

#### 第三层：枢纽识别

**去伪规则**：✅ 通过。

**枢纽判定**：

| 维度 | 分析 |
|------|------|
| 与上游（发电企业）关系 | **绝对强势。** 电网是发电企业的单一买方（单寡头买方）——发电企业的上网电量必须通过电网输送和销售。电网决定谁的电可以上网、以什么价格上网（在交易框架内）。但电网的上网电价并非完全自主决定——受政府管制的交易框架约束 |
| 与下游（用户）关系 | **绝对强势。** 用户必须通过电网购电（除少数直购电试点外），电网是电力的独家销售商。居民电价受政府严格管制（电网无法自主提价），但电网的售电价格能够完全覆盖成本（政府确保"准许收益"） |
| 与竞争端关系 | **无竞争。** 输电和配电是自然垄断——在同一区域建设两套电网是经济上荒谬的（重复投资、浪费资源）。电网是法律和政策保护的绝对垄断 |
| 利润稳定性 | **极高。** 电网的收入=输配电价×售电量。输配电价由政府核定（"成本加合理利润"），售电量随经济稳定增长。利润的稳定性是公用事业中最高的一档——不存在燃料成本波动、不存在竞争、不存在替代品 |

**横向竞争校验**：

| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ✅（CR2=100%，绝对垄断） |
| 无持续价格战？ | ✅（不存在竞争者，没有价格战的概念） |
| 新进入者未快速增加？ | ✅（法律和政策层面都不可能——电网是法定自然垄断） |

**三项全通过。判定：价值枢纽。**

**物理必经与利润占优的双重校验**：

| 校验 | 判断 |
|------|:---:|
| 物理必经？ | **S（极致）**——每一度电的生产和消费都必须经过电网（除极少量的分布式光伏自发自用）。电网是电力系统的"必经之路"的极致体现 |
| 利润占优？ | **B（受管制锁定）**——电网的利润=政府核定的"准许收益"（通常为有效资产的5-7%左右）。利润稳定且绝对金额庞大（国家电网年利润数百亿），但利润率不高且受严格管制。**你赚多少是国家定的，不是市场定的** |
| 结论 | **"物理必经"的极致+"利润占优"受限——判定为价值枢纽（通道约束型）。** 电网是特殊的"受管制的枢纽"——你绝对不可绕过，但你也不能因此而赚取超额利润。超额利润被政府核定的"准许收益"机制清零 |

**这是框架对"物理必经≠利润占优"的又一验证，但电网与医药流通有本质区别**：
- 医药流通：物理必经但不获利（利润率极薄，垫资压力大，几乎无利润留存）
- 电网：物理必经且能获得政府担保的"合理利润"（利润稳定但被锁定在5-7%的ROE上限）

电网的"利润占优"处于中间状态——不是暴利，也不是无利，而是"被锁定的合理利润"。这使电网介于"价值枢纽"和"通道型价值附属"之间，但因其利润稳定性极强（绝对金额大+不受经济周期影响），维持"价值枢纽"的判定，标注"通道约束型——利润受政府管制锁定"。

**超额利润来源**：☑ 供给刚性（极致——法定自然垄断，无替代方案） ☑ 规模经济（电网覆盖范围越广，单位成本越低）

但超额利润被政府管制清零——电网有"超额利润的潜力"（自然垄断的定价权），但没有"超额利润的实得"（被政府管制取走）。

**定价权根基**：**暴力（极致）**——你只能从电网买电（别无选择）。但这份"暴力"被政府管制约束——你不能想涨价就涨价，电价的涨跌需要发改委批准和听证会。

崩坏方式：暴力型——若出现颠覆性技术（如分布式能源+储能使配电网层面的"去电网化"成为可能）或政策变革（如电力体制改革打破电网的垄断地位——"管住中间、放开两头"的进一步深化）。当前威胁极小，但超长期（20年+）的威胁不可忽视。

**可投资性**：⚠️ **受限。** 国家电网和南方电网均未上市（央企，全民所有制）。可投资的电网资产是——国网旗下部分上市平台（国电南瑞——电网自动化和智能化设备，不是电网运营商本身；涪陵电力——配电网节能服务）。**纯正的电网运营资产在中国A股不可直接投资。**

**元枢纽追问**：电网是否跨越多个行业收税？——**是。** 电网向整个经济体收税——每一度电的消费都经过电网。**电网是公用事业中最深层的元枢纽，与支付清算网络在金融行业中的地位完全同构——都是物理必经的"最后基础设施"。**

**输出**：电网是价值枢纽（通道约束型）。枢纽成因：法定自然垄断+不可绕过+利润稳定。可投资性受限（核心标的未上市）。

#### 第四层：价值评估

**五透镜**：

| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | **S** | 极致。每一度电的生产和消费必须经过电网 |
| 粘性 | **S** | 极致。用户和发电企业都无法脱离电网——不存在"更换电网"的概念 |
| 边际成本 | A | 额外一度电的输配成本极低（电网的固定成本占比极高，额外输送一度电的边际成本趋零）。但输电损耗和配电网运维成本不为零，低于水电的S级 |
| 经常性 | **S** | 每一度电的输配都产生收入。永续现金流——只要人类用电，电网就有收入 |
| 资产效率 | C | 极重资产——电网是全社会固定资产投资最大的行业之一。输电线路、变电站、配电网——万亿级资产，ROA极低 |

**评级**：最低项资产效率（C）。三个S级。有S但有C——不触发上调规则（有两项以上C方直定C级，此处仅一项C）。**综合：B级**（最低两项为边际成本A和资产效率C，基准B级。有S无C可上调一档——但此处存在C，上调规则"有S无C"不触发——有C则不得上调。维持B级）。

**关键洞察**：电网的S级强制性和S级粘性使其物理垄断无与伦比，但资产效率C（极重资产）和边际成本A（非零）拉低了综合评级至B级。**这是"绝对的物理垄断≠绝对的高枢纽质量"的体现——即使你是任何人无法绕过的，但你的商业模式受重资产和政府管制双重约束，最终留存的利润有限。**

**护城河类型**：**根基型（极致）**——法定自然垄断+物理网络+政策性保护。电网的护城河在所有行业中最深——要摧毁电网的护城河，需要重写电力体制的基本规则，这几乎是不可能的。

**极端生存能力**：

| 维度 | 评级 |
|------|:---:|------|
| 需求刚性 | **S**（绝对） |
| 资产负债表 | B（重资产+高负债，但现金流极充裕，偿债能力强） |
| 成本灵活 | B（运维和折旧是固定成本，售电量下降时成本无法等比例缩减，但不存在火电的燃料成本风险和金融行业的挤兑风险） |

极端生存能力：**A级。** 电网的物理资产在极端环境下不受损（战争期间电网是最优先保护的设施），售电量可能因经济活动减少而下降，但需求刚性（S）确保了底线。极端生存能力弱于水电（S）和支付清算（S），但强于银行（B）。

**质量变化趋势**：

| 维度 | 趋势 | 理由 |
|------|:---:|------|
| 枢纽势能 | → | 电网的自然垄断地位不变，但分布式能源（光伏+储能）可能超长期侵蚀配电网的"必经"属性 |
| 价值留存率 | →↓ | 新能源并网和配电网升级需要巨额投资（资产端膨胀），但准许收益率的调整可能滞后，利润率有下行压力 |
| 持久性 | → | 电网在可预见的未来不可能被替代，但20年+尺度上分布式能源+微电网可能构成范式挑战 |

**自我毁灭风险评估**：极低。电网没有"自我毁灭"的驱动力——其垄断地位受法律保护，不存在压榨客户获利的冲动（因为管制不允许你多赚）。

**证伪条件设计**：
- 分布式能源+储能+微电网技术实现大规模平价，配电网层面的"去电网化"成为现实（超长期风险）
- 电力体制改革大幅降低准许收益率（如ROE从当前的5-7%降至3%以下）
- 电网垄断地位被政策打破（如配电网向第三方开放，允许其他主体经营配电网）

**最终判断**：电网是价值枢纽（通道约束型），五透镜B级+极端生存A级。**电网的特殊性在于：它是全经济体最不可或缺的基础设施（绝对物理必经），但国家对它的利润管制也是最严格的（超额利润清零）。** 这使其成为一个"终极元枢纽但中等枢纽质量"的独特存在。可投资性受限（核心标的未上市）是其作为投资对象的致命缺憾，但电网作为"理解产业链权力结构"的分析对象，具有极高价值。

## 第五部分：公用事业行业分析的核心启示

### 一、"物理必经≠利润占优"的完整图谱

公用事业是这一框架核心区分的终极检验场：

| 环节 | 物理必经 | 利润占优 | 枢纽判定 |
|------|:---:|:---:|:---:|
| 火电 | ⚠️（弱化中） | ❌ | 价值附属（C级） |
| 水电 | **S** | **S**（零燃料成本支撑） | 价值枢纽（S级） |
| 核电 | **S** | A（核燃料成本低+电价稳定） | 价值枢纽（A级） |
| 电网 | **S（极致）** | B（被管制锁定） | 价值枢纽（B级，通道约束型） |
| 水务 | A | B-C（提价受听证会限制） | 价值枢纽/周期性枢纽 |
| 燃气 | A | B（接驳费一次性，售气薄利） | 价值枢纽/周期性枢纽 |

**规律**：物理必经是价值枢纽的必要条件，利润占优是充分条件。**只有当物理必经+利润占优同时满足时，枢纽质量才能达到S/A级。** 物理必经的极致（电网）如果不能利润占优，枢纽质量被锁死在B级。物理必经趋弱（火电）且不能利润占优，直接降为价值附属（C级）。

### 二、公用事业的"管制悖论"

公用事业面临一个根本性的悖论：**行业的物理垄断越强，国家越可能强化管制以约束其定价权；管制越强，行业的枢纽质量越受限。**

| 物理垄断强度 | 管制强度 | 枢纽质量 |
|:---:|:---:|:---:|
| 电网（绝对） | 最强（准许收益） | B级 |
| 水电（资源垄断） | 中等（标杆电价） | S级 |
| 核电（牌照垄断） | 中等（标杆电价） | A级 |
| 火电（弱） | 中等（市场化交易，有天花板） | C级 |

**规律**：物理垄断越强，管制越严——电网的绝对垄断招致了最严格的"准许收益"管制，而水电和核电的资源/牌照垄断相对"低调"，管制相对宽松。**在公用事业中，最深的护城河不一定带来最高的枢纽质量——因为最深的护城河会招致最强力的监管。** 这是"反身性"在产业链分析中的体现：护城河深到极致时，国家会介入并管制——最终抑制了护城河的价值实现。

### 三、水电的"折旧跃升"逻辑

水电和核电的五透镜评级中，资产效率均为B级（巨大的初始投资）。但两者都存在"折旧期满后ROA跃升"的期权价值——水电大坝寿命百年以上，折旧期30-40年，折旧期满后运维成本极低，届时ROA将跃升。长江电力当前的利润中，折旧约占20-25%——这意味着折旧期满后，在收入不变的情况下，利润可增长约30%以上。

这是框架的五透镜在"重资产但超长寿命"资产上的一个盲区——五透镜评估的是当前的资产效率，但不考虑"折旧期满后的资产效率跃升"。这是一个重要的补充观察：**对于超长寿命的重资产（水电站、核电站、供水管网），其枢纽质量的"期权价值"在五透镜中可能被低估。**
