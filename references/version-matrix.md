## 二、双版本并行体系

框架维护**两条并行版本线**，定位不同，互不替代：

```
v9.2（长期基线） ← 并行 → v10.x（主推迭代）
     │                        │
     ├ 传统产业链分析          ├ 产业链-价值网双模
     ├ 中国语境固定            ├ 多制度环境支持（4套模板+自定义）
     ├ 四层标准分析            ├ 四层+价值网分析（第五层）
     ├ 小版本号迭代            ├ 中版本号迭代
     └ 仅文本级修订            └ 持续功能升级
```

### 维护策略

| 版本 | 维护方式 | 接受内容 |
|------|---------|---------|
| **v9.2** | 长期基线 | 仅文本级修订、案例库更新、新行业分析。**不吸收大逻辑变更** |
| **v10.x** | 主推迭代 | 新功能模块、分析维度扩展、制度环境增强 |

### 升级规则

- v9.2 → v10.x：当分析对象涉及跨行业延伸、生态化商业模式、全球利润配置、多制度环境时升级
- v10.x 内部：向后兼容，新版本包含旧版本全部功能

## 三、版本选择决策树

```
分析对象是什么？
│
├─ 传统制造业/消费行业，利润集中单一环节，仅中国语境
│   └─→ v9.2（四层标准分析即可）
│
├─ 平台型/生态型/全球化企业，或需多制度环境分析
│   └─→ v10.x（需启用价值网分析 + 制度模板）
│       └─ 涉及多国制度环境？→ 在制度模板中选择
│
└─ 不确定选哪个？
    └─→ 先用 v9.2 跑第一层
         └─ 若发现企业利润无法用位置解释 → 升级到 v10.x
```

## 六、v10.x 子版本新增模块详解

### v10.0.0 — 大逻辑变更
- **价值网构建者诊断**：区分"产业链参与者"与"价值网构建者"
- **第五层价值网分析**：主业利润真实性 / 跨价值链延伸 / 全球利润配置解码
- **能力-位置交互评估**：第三层与第四层之间的强制追问

### v10.1.0 — 全球化升级
- **国家制度环境选择**：中国 / 美国 / 欧盟 / 新兴市场（4套预置模板）
- **自定义模板**：支持 YAML/JSON 格式配置
- **跨模板评级变动警示**：切换模板后评级差异 ≥1 级自动标注
- 第零层·步骤一从"国家功率形态识别"升级为"制度环境选择+国家权力形态识别"

### v10.2.0 — 分析层次规范
- **分析层次边界声明**：行业整体 / 行业细分 / 公司层面三层次规范
- 防止层次混淆导致的评级失真

### v10.3.0 — 光谱定位
- **环节-网络光谱定位**：弃二分法，改为连续光谱
  - 网络利润占比 <30% → 强环节侧
  - 30-70% → 混合型
  - >70% → 强网络侧
- **利润溯源拆解**：环节基准利润 + 能力溢价 + 网络捕获

### v10.4.0 — 逆向评估
- **逆向评估模块**：逆向追问评级结论的脆弱性
- **动态与权力快筛**：3个快筛问题（演化轨迹 / 捕获机制 / 环节重构）
- **六大业态横向比较**：强环节侧 / 混合型 / 强网络侧的评级校准

### v10.5.0-v10.5.1 — 成熟度提升
- **常见迷思破除库**：6大常见误判模式
- **案例洞察提炼清单**：从案例中提取可复用洞察的标准流程
- **环节重构强度评分**：区分普通效率提升（3-5分）vs 颠覆性重构（8-9分）
- **综合成熟度自评**：9.2/10
