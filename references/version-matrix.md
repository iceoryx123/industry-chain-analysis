## 并行维护策略

```
v9.2（长期基线）←→ v10.x.x（主推，持续迭代）
    │                      │
    ├ 传统产业链分析         ├ 所有行业
    ├ 中国语境固定          ├ 多制度环境支持
    ├ 四层标准分析          ├ 五层（含价值网）
    └ 小版本号迭代          └ 中版本号迭代
```

- **v9.2**：作为长期基线，仅接受文本级修订、案例库更新和新行业分析，不吸收大逻辑变更
- **v10.x.x**：作为主推版本，持续迭代。传统行业用既有四层即可，复杂企业启用价值网分析

## 版本选择决策树

```
分析对象是什么？
├── 传统制造业/消费行业，利润集中单一环节
│   └── v9.2（四层标准分析即可）
├── 平台型/生态型/全球化企业
│   └── v10.x（需启用价值网分析）
├── 跨国企业，涉及多制度环境
│   └── v10.1+（需选择制度模板）
└── 只需掌握核心四层流程
    └── v10.2.0 精简版
```
