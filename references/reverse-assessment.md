# 逆向评估（v10.4.0+）

## 什么是逆向评估？

**逆向评估**：从**异常现象**出发 → 反向追问"为什么利润不按产业链位置分配？" → 识别被正向分析遗漏的力量（价值网构建者、能力溢价、全球利润配置）。

逆向评估**不是取代正向分析**，而是**正向分析的纠偏机制**。当正向分析的默认假设（位置决定利润分配）不成立时，逆向评估负责识别例外并修正结论。

## 为什么需要逆向评估？

正向分析的默认假设在以下情况会失效：
1. **企业利润显著超越环节平均** → 默认假设被打破，存在能力溢价
2. **行业外利润 > 行业内利润** → 企业已脱离单一产业链环节
3. **国内外利润结构差异显著** → 存在全球利润配置策略
4. **产业链在该国完全受控于国家权力** → 国家是终极枢纽

## 四个核心追问

### 追问1：利润来源是否集中于单一产业链环节？
- 该企业的收入利润是否主要（>60%）来自我们正在分析的产业链环节？
- 若否→该企业可能在多个价值链中同时运作，需启用价值网分析

### 追问2：该环节内是否存在企业利润显著超越同行？
- 利润率的变异系数是否远高于行业正常水平？
- 若是→存在能力溢价，需进行能力-位置交互评估

### 追问3：企业报表利润是否主要来自主业？
- 扣非后ROIC是否显著低于名义ROIC？
- 若差距>5个百分点→存在非主业利润扭曲，需检验利润真实性

### 追问4：企业的利润结构中是否存在全球制度差异利用？
- 有效税率是否持续低于法定税率10个百分点以上？
- 若是→存在全球利润配置策略，需解码其配置逻辑

## 输出与工具选择

| 逆向评估结论 | 工具选择 | 对评级的影响 |
|------------|---------|-------------|
| 纯产业链参与者无异常 | 标准四层分析 | 维持标准评级 |
| 利润来源跨行业 | 第五层价值网分析 | 补充评级维度 |
| 能力溢价存在 | 能力-位置交互评估 | 可能上调评级 |
| 全球利润配置 | 全球利润配置解码 | 标注政策脆弱性 |

## 在分析流程中的位置

```
第零层分析前强制前置
├── 步骤〇：光谱定位 ← 逆向评估追问1（利润来源集中度）
├── 步骤A：制度环境选择
├── 步骤B：国家权力形态识别
├── 步骤C：行业拆分审视
├── 步骤D：框架适用性确认

第一层~第四层：正向分析
│
├── 第三层与第四层之间
│   └── 能力-位置交互评估 ← 逆向评估追问2（环节内利润差异）
│
第五层（可选）：价值网分析 ← 逆向评估追问3和4
```

## 认知原则

1. **逆向评估不是万能的**：它只能识别"已知的逆向模式"（价值网、能力溢价、全球配置）。对于真正颠覆性的范式创新，逆向评估也无法预测。
2. **逆向评估优先于正向分析**：在第零层完成逆向评估，可避免进入正向分析后陷入"位置决定一切"的思维定势。
3. **逆向评估的结论需要证伪条件**：如"能力溢价被追平"的信号、"全球利润配置被监管封堵"的信号等。
4. **逆向评估与正向分析相互校验**：若正向分析给出A级，但逆向评估发现全球利润配置脆弱性高，则最终评级需下调半档或标注高风险。
