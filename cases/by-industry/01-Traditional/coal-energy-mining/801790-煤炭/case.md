### 拆分审视
能源行业覆盖面广，必须严格拆分。
| 触发条件 | 判断 |
|----------|------|
| 生命周期阶段不一致 | **是**——煤炭（成熟/衰退）vs 石油天然气（成熟期）vs 光伏制造（成长期/周期波动剧烈）vs 风电（成长期）vs 储能（导入/成长早期）vs 氢能（导入期） |
| 客户群体完全不同 | 部分——成品油面对消费者和交通行业，天然气面对居民和工业，煤炭面对电力系统和钢铁，光伏组件面对电站开发商 |
| 技术路线和成本结构差异显著 | **是**——油气（勘探开采+资源税，重资产+资源租金）、煤炭（开采+运输，重资产+人力密集）、光伏（制造+技术迭代，制造业属性）、风电（制造+安装，重资产+工程属性） |
| 定价逻辑不同 | **是**——油气（全球定价+OPEC+影响力）、煤炭（国内定价+长协+政策指导）、光伏（全球竞争+产能周期）、电力（政府管制） |
| 可投资标的完全不重叠 | **是**——中国神华（煤炭）、中国海油（油气）、隆基绿能（光伏）、三峡能源（新能源发电）是完全不同的投资标的 |
**拆分结论**：必须拆分为以下最小可分析单位：
1. **传统能源——油气**（石油勘探开采、天然气、油服工程）
2. **传统能源——煤炭**（动力煤、焦煤、煤化工）
3. **新能源——光伏**（硅料、硅片、电池、组件、逆变器）
4. **新能源——储能**（锂电池储能、钠电池、液流电池、抽水蓄能）
5. **电力系统**（发电、电网、售电——已在公用事业中分析火电/水电/核电/电网，本次补充光伏发电和风电运营）

### 第二部分：分析前强制前置
### 第零层·步骤一：国家权力形态识别
能源行业的国家权力形态比医药和公用事业更加复杂——因为它同时涉及国内政策和国际博弈。
| 能源子行业 | 国家权力形态（国内） | 国际维度 | 对产业链的影响方向 |
|-----------|-------------------|---------|:---:|
| **油气** | **资源所有权**（国家拥有地下资源）+**特许经营权**（三桶油垄断）+**定价管制**（成品油地板/天花板价、天然气门站价）+**能源安全战略**（增储上产） | 全球定价（布伦特/WTI）、OPEC+产量博弈、地缘政治（俄乌、中东）、海上通道安全（马六甲） | →↓ 三桶油有牌照壁垒但利润受定价管制和资源税约束；国际油价波动是最大变量 |
| **煤炭** | **资源所有权**+**产能管制**（供给侧改革去产能）+**长协定价**（电煤长协价机制）+**安全生产监管**+**碳达峰约束**（煤电装机上限） | 进口煤调节（澳煤/印尼煤）、国际煤价联动弱于油气 | →↓ 产能管制强化在位者壁垒，但长协锁定利润上限，碳达峰约束结构性削弱需求 |
| **光伏制造** | **产业政策引导**（补贴退坡→平价上网）+**产能管制（间接）**（能耗双控、产能过剩风险提示）+**贸易政策**（出口退税、光伏产品贸易摩擦） | 全球竞争（中国光伏占全球产能80%+）、欧美反倾销/反补贴关税、美国涉疆法案（UFLPA）、印度ALMM清单 | ↓ 无牌照壁垒（制造业自由竞争），利润完全取决于产能周期和技术迭代 |
| **储能** | **产业政策支持**（新型储能发展规划、储能补贴、电力市场化改革——储能参与电力市场交易）+**安全监管**（锂电池储能消防安全标准趋严） | 全球竞争（中国锂电池储能占全球产能优势）+关键矿物进口依赖（锂/钴/镍） | ↑ 政策强力支持创造增量市场，但竞争激烈（制造业属性） |
**核心判断**：
- **油气/煤炭**：国家供给管控型——资源所有权+特许经营权强化了三桶油和大型煤企的壁垒，但定价管制和碳约束限制了其利润留存能力。**这是"公用事业化"的传统能源——物理必需，但利润受管制。**
- **光伏制造**：**接近完全市场竞争**——无牌照壁垒、无资源稀缺性、技术迭代快。国家的产业政策是"扶持但不兜底"——补贴退坡后，企业生死由市场竞争决定。**这是能源行业中"最像制造业"的子行业——技术进步创造价值，但产能周期摧毁利润。**
- **储能**：**政策红利期**——国家明确支持储能发展（解决新能源消纳的关键瓶颈），政策创造增量市场。但进入壁垒有限（制造属性），竞争已在加剧。

**关键特征**：油气的"成熟"不是增长见顶，而是**增长模式转换**——从"资源扩张"转向"存量运营+低碳转型"。中国三桶油在"增储上产"（能源安全驱动）和"低碳转型"（碳中和约束）之间寻求平衡。
**假衰退检验**：不适用。石油需求未进入系统性萎缩（尚未达峰）。
**输出**：成熟期。非假衰退。框架适用。

**拐点判断**：**趋势转折点在中变量层面酝酿——全球石油需求达峰是确定性事件，但时点高度不确定（2028-2035年）。** 达峰后石油行业将从"增量竞争"转向"减量博弈"——高成本产能率先退出，低成本产能（中东、中国海上油气）仍有利可图。天然气作为"过渡能源"的生命周期更长（2035年后才可能达峰）。
**确信度**：A级（方向确定），C级（节奏不确定——达峰时点预测分歧巨大）。
#### 第二层：空间定位——行业属性与利润池
**通用属性**：
| 属性 | 判断 |
|------|------|
| 周期性 | **极强周期性**——油价是典型的周期品，受全球供需、OPEC+政策、地缘政治、金融市场多重影响 |
| 资产属性 | **极重资产**——上游勘探开发（深海钻井平台、LNG液化设施）投资巨大，资产专用性强（无法转产） |
| 监管属性 | **强监管**——资源所有权国有+特许经营权（三桶油垄断）+成品油/天然气定价受政府指导 |
| 技术迭代速度 | 慢——勘探开发技术进步（页岩油革命、深海技术），但技术迭代速度远慢于新能源 |
| 政策依赖度 | **极高**——能源安全政策决定国内产量目标，碳中和政策决定长期需求路径，成品油定价机制决定利润空间 |
**赛道基因**：**周期/资源型**（极致——石油是周期品的代名词）。
默认枢纽分布：**资源拥有者层**。
**产业链分层**：
上游：**油气资源**（地下储量——国家所有）→ 勘探与开采（三桶油+国际油公司）→ 油服工程（中海油服、贝克休斯等——提供钻井、物探等技术服务）
中游：管道运输（国家管网——长输管道）+ LNG运输 + 存储
下游：炼化（炼油厂→成品油；乙烯裂解→化工品）→ 成品油零售（加油站）→ 天然气分销（城市燃气）
**关键观察**：
1. **上游资源是产业链的核心约束。** 中国是"富煤贫油少气"的国家，石油对外依存度约70%，天然气约40%。能源安全（降低对外依存度）是国家战略——这意味着国内增储上产是政治任务，而非纯粹的经济决策。
2. **中游管网已完成"网运分离"改革。** 国家管网集团（2019年成立）垄断了全国油气长输管道——这是与电网同构的"通道型"环节。管网对上下游具有极强议价能力，但受国家管制（准许收益）。
3. **下游炼化和零售利润薄。** 成品油零售市场竞争激烈（三桶油+民营加油站），炼化产能过剩。
#### 第三层：枢纽识别
**起点规则**：从资源拥有者层出发。
**去伪规则**：✅ 通过。
**枢纽判定**（以三桶油的上游业务为核心分析对象）：
| 维度 | 分析 |
|------|------|
| 与上游（资源）关系 | 油气资源是国家所有。三桶油是"特许经营权人"——获得勘探开发许可，缴纳资源税和特别收益金（"暴利税"）。**对资源本身无议价能力（资源不是买的，是国家的）** |
| 与中游（管网）关系 | 管道运输是国家管网集团垄断。三桶油是管网的"货主"——输送油气必须经过国家管网。国家管网按准许收益收费，三桶油无议价空间 |
| 与下游（炼化/消费者）关系 | 成品油零售价受政府管制（"地板价"和"天花板价"机制）。国际油价低于40美元/桶时不下调（保护炼油利润），高于130美元/桶时不上调（保护消费者）。**三桶油的利润空间被成品油定价机制锁定** |
| 利润稳定性 | **极不稳定**——油价的周期性波动决定了三桶油的利润。2020年油价暴跌（布伦特一度跌至负值），中石油中石化巨亏；2022年油价暴涨，利润创历史新高。**这是资源品周期股的典型特征——利润不取决于企业自身，取决于商品价格** |
**横向竞争校验**：
| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ✅（三桶油在上游几乎完全垄断，但对国际油价无定价权——中国是价格接受者） |
| 无持续价格战？ | ✅（不存在价格战——油价是全球定价） |
| 新进入者未快速增加？ | ✅（上游勘探开采准入壁垒极高——资本+技术+政府许可） |
**三项全通过。判定：价值枢纽（周期性）。**
**但需区分"国内位置"和"全球位置"**：
- 在国内产业链中，三桶油的上游业务是**价值枢纽**——资源勘探开发的特许经营权+能源安全的战略地位赋予其不可替代性。
- 在全球定价体系中，三桶油是**价格的被动接受者**——油价不由三桶油决定，由全球供需和OPEC+决定。三桶油的利润是全球油价的函数。
**超额利润来源**：☑ 牌照保护（特许经营权——国内垄断） ☑ 供给刚性（资源稀缺——地下石油储量有限）。但超额利润的实现依赖油价周期——油价高时有超额利润，油价低时可能亏损。
**定价权根基**：在国内是**暴力**（成品油消费者别无选择——必须加油），但这份"暴力"被成品油定价机制约束（不能无限涨价）。在国际是**无定价权**（价格接受者）。
崩坏方式：暴力型——若新能源汽车大规模替代燃油车（加油需求结构性下降），加油站的"必经"属性将被侵蚀。能源转型是油气行业长期面临的最大结构性威胁。
**可投资性**：☑ 可投资（中国海油 600938.SH/00883.HK——最纯正的上游油气标的；中国石油 601857.SH——上游+炼化+零售一体化）。
**元枢纽追问**：否。三桶油是国内能源体系的"关键供应商"，但不向其他行业收税。
**跨行业依赖关系**：依赖全球石油市场定价（被动接受），依赖国家管网（共生关系）。
**输出**：三桶油的上游油气业务是价值枢纽（周期性枢纽——枢纽地位取决于油价周期和国内特许经营权）。定价权在国际市场缺失，在国内受成品油定价机制约束。
#### 第四层：价值评估（以中国海油——上游纯正标的为对象）
**A. 五透镜**：
| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | **S**（当前）→ B-C（长期） | 当前：石油是交通和工业的绝对必需品，无可替代（S级）。长期：新能源汽车替代燃油车、清洁能源替代化石能源，强制性将结构性下降 |
| 粘性 | C | 消费者对加油站的品牌无粘性（哪个加油站近去哪个，哪个便宜去哪个）。成品油是同质化产品，不同品牌之间无差异 |
| 边际成本 | C | 额外一桶油的勘探开发成本极高（深海钻井、页岩油开采的边际成本高昂）。油气是典型的高边际成本行业——完全不同于软件的S级 |
| 经常性 | A | 石油消费是持续行为（每日交通+工业生产），收入持续 |
| 资产效率 | C | 极重资产（海上钻井平台、LNG工厂），资产回报率高度取决于油价 |
**评级**：最低项粘性（C）、边际成本（C）、资产效率（C）。三项C级。两项及以上C直定C级。**综合：C级。**
**关键洞察**：这是框架给出的一个极具张力的评级。三桶油的上游业务在产业链中是**价值枢纽**（横向竞争校验三项全通过），但五透镜评级仅为**C级**——粘性低、边际成本高、资产效率低，只有强制性（当前）和经常性支撑。
**这揭示了"牌照型周期性枢纽"的本质**：进入壁垒极强（牌照+资源），但商业模式效率（边际成本+粘性+资产效率）被资源品的物理属性先天锁死。**油气是"有护城河，但护城河内不是金矿，是油井——开采成本高、价格不由你定、客户随时会换（新能源替代）。"**
**护城河类型**：**根基型**（特许经营权+资源储量+历史投入）——三桶油的护城河不是"奔跑"来的，是"存在"本身（国家赋予的垄断地位）。但根基型护城河的价值实现受限于商品价格周期。
**B. 极端生存能力**：
| 维度 | 评级 |
|------|:---:|------|
| 需求刚性 | A（当前——交通和工业必需）→ B-C（长期——新能源替代） |
| 资产负债表 | B（三桶油有大量有息负债，但现金流在正常油价下充裕。油价暴跌时资产负债表承压——2020年曾出现巨亏） |
| 成本灵活 | C（勘探开发是极高固定成本的业务——钻井平台一旦开钻无法暂停，深海油田的运维成本刚性。收入下降时利润断崖降） |
极端生存能力：**B级**（当前）→ C级（长期）。油气的极端生存能力弱于水电（S）和核电（A-S）——因为成本结构刚性+商品价格波动+长期需求的结构性下降。
**D. 质量变化趋势**：
| 维度 | 趋势 | 理由 |
|------|:---:|------|
| 枢纽势能 | ↓ | 长期来看，能源转型将结构性削弱石油的"必需品"地位。天然气作为过渡能源的枢纽势能相对稳定 |
| 价值留存率 | →↓ | 石油价格中枢可能因需求达峰而下移（长期），但低成本产能（中国海油的深海油气）仍可维持合理利润 |
| 持久性 | ↓ | 石油需求达峰后，行业将进入结构性萎缩。这是一个"数十年慢衰退"的行业，不是突然消亡 |
**自我毁灭风险评估**：
| 类型 | 评估 |
|------|------|
| 傲慢型 | **高**——石油企业可能低估能源转型的速度，拒绝低碳投资，最终陷入"搁浅资产"陷阱——持有的油气储量在碳约束下失去开采价值 |
| 惯性型 | **中高**——满足于传统油气业务，忽视新能源和低碳技术的布局。国际石油巨头（壳牌、BP）已积极转型，中国三桶油的转型步伐相对审慎 |
| 自噬型 | 中——过度投资高成本产能（如深海、极地），在需求达峰后成为沉没成本 |
**证伪条件设计**：
- 根基型护城河证伪：新能源汽车在中国新车销售中的渗透率超过80%+存量替代加速（加油站需求断崖下降）；全球石油需求在2030年前达峰并持续下降
- 定价权证伪（国内）：成品油定价机制取消（完全市场化），三桶油的零售利润被民营加油站和新能源替代侵蚀
- 商品价格证伪：布伦特油价长期低于60美元/桶（深海油气开采成本线附近），高成本产能持续亏损
**最终判断**：油气（中国海油）是价值枢纽（周期性），五透镜C级+极端生存B级。**枢纽地位的"当前强度"和"长期趋势"出现巨大张力——当前石油是绝对必需品（强制性S级），但长期被能源转型结构性削弱。** 这是一个"在确定性下降趋势中的阶段性价值枢纽"——适合作为周期配置，不适合作为"永续持有"的核心仓位。天然气是油气行业中最具韧性的细分方向（过渡能源，需求增长期更长）。
### B. 传统能源——煤炭
#### 第一层A：时间定位——行业生命周期
| 维度 | 判断 |
|------|------|
| 阶段判定 | **成熟期向衰退期过渡**。在碳中和目标下，煤炭是中国能源转型中承受最大压力的化石能源。"十五五"期间煤电装机将达峰后下降（被新能源+储能替代）。但煤炭在短期内（10-15年）仍是电力系统的"压舱石"——新能源间歇性需要煤电调峰和兜底 |
| 需求增速 | 零增长到负增长。煤炭消费量已接近峰值，预计2025-2030年间达峰后缓慢下降 |
| 渗透率 | 煤炭在中国一次能源消费中占比约56%（已从2010年的69%大幅下降），长期目标降至40%以下 |
| CR3 | 极高（中国神华、中煤能源、陕煤集团等头部煤企占据产能的大部分份额）。供给侧改革（2016-2020年去产能）加速了行业向头部集中 |
**输出**：成熟期向衰退过渡。非假衰退（需求达峰后的结构性下降）。框架适用。
**是否需要启动重生识别？** 煤炭的"需求火种"未灭（电力调峰需求、煤化工原料需求仍在），但结构性下降是确定性趋势。**若煤化工（煤制油、煤制气、煤制烯烃）大规模需求增长，或CCUS（碳捕集利用与封存）使煤炭实现"零碳化"，煤炭可能部分重生。** 当前不满足重生前提条件（触发力量——煤化工或CCUS——尚未大规模出现），不启动重生识别。标注为"重生观望期"。
#### 第二层：赛道基因
**周期/资源型**（煤炭是典型的资源品）。
默认枢纽分布：**资源拥有者层**。
#### 第三层：枢纽识别
**去伪规则**：✅ 通过。
**枢纽判定**：
| 维度 | 分析 |
|------|------|
| 与上游（资源）关系 | 煤炭资源由国家所有，采矿权出让。大型煤企拥有优质储量和低成本矿井——资源禀赋决定一切。低成本露天矿（神华）具有绝对成本优势，高成本井工矿在煤价下行时率先亏损 |
| 与下游（电力/钢铁/化工）关系 | **核心博弈**：电煤长协价机制。政府主导的电煤长协价（年度长协+月度长协）锁定了大型煤企与电力企业之间的量价关系——"基准价+浮动价"。长协价低于市场价但稳定，市场价随行就市。**煤企的利润被长协价锁定上限，但也获得保底** |
| 与竞争端关系 | 供给侧改革后行业集中度大幅提升（CR3份额40%+），但煤炭仍是同质化产品。竞争力来自成本（资源禀赋+运输成本）——"谁离港口近、谁的开采成本低、谁的煤质好" |
| 利润稳定性 | **极不稳定（历史）→趋于稳定（供给侧改革后）**。2012-2015年煤炭全行业巨亏（产能过剩+煤价暴跌），2016年供给侧改革后利润修复，2021-2022年煤价暴涨带来暴利，此后回落但维持在合理水平。长协价机制的推广降低了利润波动 |
**横向竞争校验**：
| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ✅（CR3>40%，长协价机制给予煤企集体议价能力。但在政府主导的长协框架下，价格弹性受限） |
| 无持续价格战？ | ✅（供给侧改革消除了产能过剩，行业从"供过于求"转向"紧平衡"。长协价避免了价格战） |
| 新进入者未快速增加？ | ✅（新增产能审批极为严格——"双碳"目标下新煤矿审批基本冻结。在位者的资源禀赋壁垒极强） |
**三项全通过。判定：价值枢纽（周期性，受长协价约束）。**
**超额利润来源**：☑ 供给刚性（资源稀缺——优质低成本储量不可复制）+ ☑ 牌照保护（采矿权审批严格、新矿审批冻结）。
**定价权根基**：在国内是**暴力**（发电厂必须用煤——煤电是电力系统的主力电源），但这份"暴力"被长协价机制和"碳达峰"约束双重削弱。
崩坏方式：暴力型——若新能源+储能完全替代煤电（电力系统的煤炭需求归零），煤炭将丧失"必经"属性。这一过程需要数十年，但趋势是确定的。
**可投资性**：☑ 可投资（中国神华 601088.SH/01088.HK——煤电运一体化，纯正度极高）。
**输出**：大型煤企是价值枢纽（周期性，受长协价约束）。枢纽地位来自资源禀赋+产能管制+长协价兜底。
#### 第四层：价值评估（以中国神华为对象）
**五透镜**：
| 透镜 | 评分 | 理由 |
|------|:---:|------|
| 强制性 | **S**（当前）→ B（长期） | 当前：煤电是电力系统的绝对主力（占比55-60%），新能源无法完全替代。长期：新能源+储能逐步替代，强制性下降 |
| 粘性 | C | 发电厂对特定煤企的粘性为零——同质化产品，谁便宜买谁。神华的优势在于"煤电运一体化"——自有铁路和港口降低运输成本，但这不属于粘性 |
| 边际成本 | C | 额外一吨煤的开采成本不低——矿井开采的边际成本较高 |
| 经常性 | A | 发电是持续行为，煤炭消费持续 |
| 资产效率 | C | 极重资产（矿井+铁路+港口），资产周转率低 |
**评级**：三项C级。**综合：C级。** 与油气完全同构——价值枢纽的产业链位置，但五透镜评级受资源品的物理属性锁死在C级。
**护城河类型**：**根基型**（资源禀赋+产能管制）。神华的护城河来自其"煤电运港"一体化——煤炭储量+自有铁路+黄骅港+配套电厂，是全产业链成本最低的煤企。
**极端生存能力**：
| 维度 | 评级 |
|------|:---:|------|
| 需求刚性 | A（当前）→ B-C（长期） |
| 资产负债表 | A（中国神华极低负债+巨额现金——与中国海油类似） |
| 成本灵活 | C（开采成本刚性，煤价暴跌时利润断崖降） |
极端生存能力：**B级**。与油气同构——低成本产能（神华）在煤价下行周期中具有更强的生存能力。
**质量变化趋势**：
| 维度 | 趋势 | 理由 |
|------|:---:|------|
| 枢纽势能 | ↓ | 碳中和趋势下煤电份额确定性下降。但下降是缓慢的（10年以上尺度） |
| 价值留存率 | →↓ | 长协价机制稳定了利润下限，但长期煤价中枢可能随需求达峰而下行 |
| 持久性 | ↓ | 煤炭需求达峰后的结构性下降是确定性趋势。煤化工和CCUS可能提供部分对冲，但规模不足以逆转整体趋势 |
**自我毁灭风险评估**：
| 类型 | 评估 |
|------|------|
| 傲慢型 | **高**——煤企可能低估能源转型的速度，在周期顶部（高煤价时）过度投资新产能，在需求达峰后成为搁浅资产 |
| 惯性型 | **高**——满足于"压舱石"地位，拒绝向新能源和低碳技术转型 |
**证伪条件**：
- 新能源+储能成本降至低于煤电（煤电经济性彻底丧失）
- 碳价大幅上升（如碳配额价格升至200元/吨以上），煤电的碳成本吞噬全部利润
- 煤化工或CCUS未能在10年内实现大规模商业化（煤炭的"重生"希望破灭）
**最终判断**：煤炭（中国神华）是价值枢纽（周期性），五透镜C级+极端生存B级。与油气完全同构——**"在确定性下降趋势中的阶段性价值枢纽"。** 在能源转型完成之前（可能10-15年），低成本大型煤企仍可通过长协价获得稳定利润和高分红。但长期来看，这是一个结构性衰退的行业——适宜作为"高股息周期配置"，而非"永续持有"。
### C. 新能源——光伏制造
#### 第一层A：时间定位——行业生命周期
| 维度 | 判断 |
|------|------|
| 阶段判定 | **成长期（需求端），但制造业周期剧烈波动（供给端）。** 全球光伏新增装机以每年20-30%的速度增长，渗透率仍有数倍空间。但制造端面临严重的产能过剩和价格战——这是"成长行业的周期性崩溃" |
| 需求增速 | 高增速。全球光伏装机2024年约500GW，预计2030年有望达1000GW——年复合增速约15-20% |
| 渗透率 | 低。光伏在全球发电量中的占比仅约6%，有大幅提升空间 |
| CR3 | 极高（中国企业在硅料、硅片、电池、组件各环节均占据全球80%+的份额），但环节内部竞争极度激烈 |
**假衰退识别**：光伏制造在2023-2025年经历的全行业亏损和价格暴跌，是**假衰退**——本质是超高速成长期内的严重供需错配（产能扩张速度远超需求增速）。需求端仍在高增长（年增20-30%），亏损原因是供给过剩而非需求萎缩。**假衰退期内不修改生命周期判断（仍为成长期），启动生存能力三角识别出清幸存者。**
**输出**：成长期，经历假衰退（供给过剩型）。框架适用。
#### 第二层：赛道基因
**科技/成长型**（技术迭代快——TOPCon、HJT、BC、钙钛矿等新技术路线竞逐）+ **制造业/周期型**（产能周期+同质化竞争+规模效应）。
默认枢纽分布：光伏制造——不同环节的枢纽属性可能不同，需分别分析。
**产业链分层**：
上游：硅料（多晶硅——通威股份、大全能源、协鑫科技）→ 硅片（隆基绿能、TCL中环）→ 电池片（通威、爱旭、钧达）→ 组件（隆基、晶科、天合、晶澳）→ 逆变器（阳光电源、华为）→ 电站开发/EPC
**关键观察**：光伏制造是典型的技术密集型+资本密集型制造业。各环节的壁垒和定价权差异显著——硅料环节曾因产能紧缺（2021-2022年）获得极高利润率，硅片和组件环节同质化竞争最激烈。
#### 第三层：枢纽识别
**光伏制造的枢纽分析需要分环节进行：**
**环节一：硅料（多晶硅）**
| 维度 | 分析 |
|------|------|
| 壁垒 | 极高——硅料是化工属性，投资巨大（万吨投资数十亿元）+建设周期长（18-24个月）+技术门槛高（纯度要求极高）。新进入者极难进入 |
| 定价权 | 在产能紧缺周期（2021-2022年）中具有极强定价权——硅料占组件成本高达40%，组件厂"求着硅料厂发货"。但在产能过剩周期（2023-2025年）中定价权大幅削弱 |
| 竞争格局 | CR5>80%，头部集中度高 |
**判定**：硅料环节是**周期性枢纽**——在产能紧缺周期中是价值枢纽，在产能过剩周期中是周期性枢纽（利润被压缩但不会归零，因为成本优势决定了底部）。**硅料的"枢纽属性"来自于化工属性（高壁垒+长周期+不可逆投资），而非技术品牌。**
**环节二：硅片/电池/组件**
| 维度 | 分析 |
|------|------|
| 壁垒 | 中低——设备由供应商提供（晶盛机电、捷佳伟创等），制造工艺趋同。头部企业通过规模效应和一体化布局降本，但技术壁垒有限 |
| 定价权 | 极弱——组件是同质化产品（功率和效率虽有差异，但对电站开发商而言是可替代的），价格由市场供需决定。产能过剩时价格战惨烈 |
| 竞争格局 | 集中度高但内卷——CR5>60%，但头部企业之间仍在激烈价格战 |
**横向竞争校验（组件环节）**：
| 校验项 | 通过？ |
|--------|:---:|
| 集中度支撑定价权？ | ❌（CR5虽高，但同质化竞争严重，光伏组件是拍卖式的买方市场——电站开发商标价招标，组件厂报价竞标） |
| 无持续价格战？ | ❌（价格战是光伏制造的常态——2023年组件价格从2元/W暴跌至0.8元/W，全行业亏损） |
| 新进入者未快速增加？ | ❌（技术扩散+设备国产化+资本市场融资使新进入者不断涌入，2021-2023年跨界进入光伏的企业超过50家） |
**三项全否。判定：价值附属。**
**关键洞察**：光伏制造的"悲剧"在于——它是能源转型的绝对主角（需求高增长），但制造环节的价值被技术扩散和产能周期完全吞噬。**光伏制造是"好行业中的差生意"——与证券基金业、餐饮连锁同构。** 价值枢纽不在制造环节，而在以下环节：
- **逆变器（阳光电源、华为）**：技术壁垒更深（电力电子+软件+电网适配性），品牌和渠道粘性更强，竞争格局优于组件。
- **光伏电站运营（三峡能源、正泰电器）**：资源选址（光照资源）+长期购电协议（PPA）创造稳定现金流——类似于水电的逻辑（但寿命25年 vs 百年）。
- **光伏设备（晶盛机电、捷佳伟创）**：卖铲人——不管谁做组件，都要买设备。
**可投资性**：☑ 可投资，但**仅推荐成本最低、技术最领先的头部一体化企业（通威股份 600438.SH——硅料+电池双龙头；隆基绿能 601012.SH——硅片+电池+组件，技术领先）**。投资光伏制造是投资"成本曲线最左端"的幸存者，而非产业链位置优势。
**最终判断**：光伏制造整体为价值附属（周期性枢纽仅存在于硅料环节的紧缺期）。行业的核心矛盾是"成长的痛苦"——需求高增长诱发了过度投资，产能过剩摧毁了价格和利润。只有成本最低、技术最领先的企业能穿越周期，但这也属于企业竞争优势，而非产业链位置优势。
### D. 新能源——储能
#### 第一层A：生命周期
| 维度 | 判断 |
|------|------|
| 阶段判定 | **成长早期。** 新型储能（锂电池储能为主）正处于爆发式增长初期。全球电化学储能累计装机从2020年的23GW增至2024年的约200GW，预计2030年有望超过1000GW。储能是解决新能源消纳的"必选项"——没有储能，光伏和风电的间歇性将限制其渗透率上限 |
| 需求增速 | 极高增速（年增50%+），但基数仍低 |
| 渗透率 | 极低——储能占电力系统调峰能力的比例仍很小，潜在市场空间巨大 |
| CR3 | 高（宁德时代、比亚迪、阳光电源在储能电池和PCS领域占据主导份额），但竞争已在加剧 |
**输出**：成长早期。非假衰退。框架适用。
#### 第二层：赛道基因
**科技/成长型**（锂电池技术迭代+钠电池/液流电池等新兴技术路线）+ **制造业/周期型**（锂电池储能同样面临产能周期风险——2023年储能电池产能已出现过剩迹象）。
默认枢纽分布：储能的价值枢纽分布需要分别分析——**储能电池**（制造业，类似光伏组件）vs **储能系统集成**（品牌+渠道+运维）vs **储能电站运营**（资源型，类似光伏电站）。
#### 第三层：枢纽识别
**环节一：储能电池（电芯）**
| 维度 | 分析 |
|------|------|
| 壁垒 | 高——锂电池电芯的技术壁垒和规模壁垒显著（宁德时代的制造良率和成本控制领先同行），但技术扩散风险存在（比亚迪、亿纬锂能、国轩高科等追赶） |
| 定价权 | 有限——储能电芯是标准品，技术参数趋同（280Ah/314Ah电芯成为行业标准），价格由供需决定。2023-2024年储能电芯价格因产能过剩暴跌 |
| 竞争格局 | 高度集中（宁德时代市占率35%+，CR3>60%），但价格竞争激烈 |
**判定**：储能电芯是**周期性枢纽**——与光伏硅料类似，在产能紧缺期有极强议价权，在产能过剩期利润被压缩。宁德时代的竞争优势（制造效率+研发+客户关系）使其在行业低谷时仍能维持相对利润，但这来自企业能力而非产业链位置。
**环节二：储能系统集成**
| 维度 | 分析 |
|------|------|
| 壁垒 | 中等——集成技术壁垒有限（电芯+PCS+BMS+EMS的组合），核心壁垒在于品牌+项目经验+售后服务+电网适配能力 |
| 定价权 | 有限——储能系统招标是价格竞争（最低价中标），差异化有限 |
| 竞争格局 | 分散——阳光电源、比亚迪、华为、海博思创等众多玩家 |
**判定**：储能系统集成是**价值附属**（当前）向**周期性枢纽**（品牌和渠道沉淀后）过渡。阳光电源和华为在海外储能市场具有品牌溢价（"中国逆变器/储能第一品牌"），但在国内市场仍是价格竞争。
**环节三：储能PCS（储能变流器）**
| 维度 | 分析 |
|------|------|
| 壁垒 | 高——PCS是电力电子设备，与光伏逆变器技术同源但更复杂（双向充放电+电网适配+响应速度）。头部企业（阳光电源、华为）的技术积累和品牌壁垒深厚 |
| 定价权 | 较强——PCS的差异化程度高于电芯和集成，电网对PCS的并网性能要求高，品牌信任重要 |
| 竞争格局 | 集中度高（阳光电源市占率30%+，华为紧随其后） |
**判定**：储能PCS是**价值枢纽**（接近光伏逆变器的逻辑——技术壁垒+品牌+渠道粘性）。
**可投资性**：☑ 可投资（阳光电源 300274.SZ——光伏逆变器+储能PCS+储能系统集成，全球龙头；宁德时代 300750.SZ——储能电芯全球龙头）。
**输出**：储能行业的价值枢纽不在电芯和系统集成环节（制造业属性，产能周期和价格竞争），而在**PCS**（技术+品牌壁垒）和**储能电站运营**（资源型，稳定现金流——但尚未有大规模纯正上市标的）。阳光电源是储能价值链中最接近价值枢纽的位置——PCS的技术壁垒和品牌溢价使其避免了电芯的产能周期风险。

### 第五部分：能源行业分析的核心启示
### 一、"成长的痛苦"——能源转型中的"好行业，差生意"
光伏制造是能源行业分析的最重要警世案例——它是人类历史上增长最快的能源技术（光伏装机年增20-30%），但制造环节的投资者可能血本无归。这不是特例，而是规律。高速成长的行业吸引过度投资→产能过剩→价格战→全行业亏损→出清→幸存者获得合理利润→下一轮扩张。这一周期在光伏、面板、LED、风电中反复上演。
**框架的贡献**：帮助分析者区分"行业增长"和"利润留存"。光伏行业在增长（需求端极好），但制造环节不赚钱（供给端过度竞争）。赚钱的环节可能在**技术壁垒更深**的（逆变器/PCS）、**资源稀缺**的（光照资源好的光伏电站）、**提供服务而非制造产品**的（运维、EPC）。
### 二、资源品的"五透镜诅咒"
油气和煤炭在五透镜中均获得C级——不是因为它们的产业链位置不重要，而是因为资源品的物理属性锁死了商业模式效率：
| 资源品特征 | 五透镜对应 | 评级 |
|-----------|:---:|:---:|
| 同质化产品 | 粘性 | C |
| 高开采成本 | 边际成本 | C |
| 重资产 | 资产效率 | C |
| 刚性成本结构 | 极端生存-成本灵活 | C |
**资源品在五透镜评估中几乎注定是C级——这是框架对"资源诅咒"的量化表达。** 资源品的价值在于**价格周期**——在商品价格上行周期中，C级资产可以产生巨额利润（2022年油价暴涨使海油利润创历史新高）。投资资源品是投资"周期"，而非"质量"。
### 三、储能——能源转型的"必选基础设施"
储能是本次分析中发现的能源行业最具成长性的价值枢纽之一。储能PCS（阳光电源）获得A级评级——与运动鞋服、血制品、核电同级。储能的"必经"属性来自新能源消纳的物理约束——没有储能，光伏和风电的渗透率无法突破15-20%（受间歇性限制）。**储能是能源转型的"搭桥者"——它的成长确定性来自光伏和风电的成长确定性。**
但储能同样面临制造业的产能周期风险——电芯环节的竞争格局和产能过剩风险需要持续关注。价值枢纽的识别需要聚焦于壁垒更深的环节（PCS、运维服务、软件/EMS）。
### 四、能源行业与公用事业、房地产的"同构性"
| 能源子行业 | 公用事业/房地产对应 | 同构逻辑 |
|-----------|-------------------|---------|
| 油气/煤炭 | 火电 | 重资产+商品价格周期+长期需求结构性下降 |
| 光伏制造（组件） | 住宅开发 | "好行业中的差生意"——行业增长不意味着制造环节赚钱 |
| 逆变器/PCS | 口腔正畸品牌商/代建 | 轻资产+技术壁垒+品牌+全球可复制 |
| 光伏/风电电站运营 | 水电（弱化版） | 资源选址+长期PPA+稳定现金流（但寿命和成本结构不如水电） |
| 储能电站运营 | 电网（部分同构） | 物理必需+调峰服务的"通道"价值 |
